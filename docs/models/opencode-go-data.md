## 导语：开发者投出来的模型排行榜

OpenCode Go 不是测试榜单，而是开发者每天用真金白银“投”出来的真实数据。我把 `/zh/data` 主页面及多个模型子页面里的实时数据捞出来后发现：

- **Qwen3.7 Plus 增速最快**，可能成为第二梯队的最大变量；
- **最耐人寻味的是全球分布**——中国仅占 16%，美国、巴西、日本、印尼、德国、印度等开发者都在大量使用。

这为中国 AI 出海提供了一个非常生动的样本：国产模型正在全球范围内被开发者真实采用。

### 5.4 地理洞察

**1. 中国不是全部，海外市场非常分散**

**3. 欧洲以德、西、法、英、俄、意为主**  
德国和西班牙的占比甚至高于日本和英国，欧洲开发者对 Agent/代码助手的需求也在快速增长。意大利、波兰、荷兰等国也有 1% 以上份额。

**4. 中国香港、新加坡、中国台湾是重要桥头堡**  
这三个地区合计份额约 8%，加上越南、马来西亚、泰国，东南亚华语/英语开发者生态圈非常活跃。

### 6.2 效率洞察

1. **缓存率普遍 90%+**  
   这是 Agent 平台的典型特征：长上下文、重复调用、重复 prompt。谁能把缓存价格打下来，谁就掌握成本优势。

2. **MiMo-V2.5 和 DeepSeek V4 Flash 是最便宜的“日常搬砖”选择**  
   每会话成本分别只有 $0.05 和 $0.08 左右。这解释了为什么 DeepSeek V4 Flash 能成为绝对主力。

3. **GLM-5.2 的缓存率只有 82.4%**  
   这是头部模型里最低的，直接导致其实际会话成本高达 $2.34，是 DeepSeek V4 Flash 的 27 倍。这会影响它在长上下文场景中的竞争力。

4. **输出 token 比输入 token 贵 2–10 倍**  
   代码生成类应用的成本主要来自输出。Kimi K2.7 Code 虽然代码能力强，但输出价 $3.50/1M，导致每会话成本高达 $1.02。

## 七、头部模型特写

### 7.1 DeepSeek V4 Flash：默认选项

- **定位**：经济型推理、代码、长上下文任务
- **价格**：输入 $0.14/1M，输出 $0.28/1M，缓存读 $0.0028/1M
- **7 日 tokens**：8,708 B
- **每会话成本**：$0.08
- **每会话 tokens**：835 万
- **缓存率**：95.9%

**判断**：这是目前性价比最高的“日常搬砖”模型。价格低、缓存好、会话成本低，开发者明显把它当成默认调用模型。

### 7.2 DeepSeek V4 Pro：复杂任务的“重型武器”

- **定位**：MoE 旗舰，百万 token 上下文，适合长 Agent 运行和复杂代码
- **价格**：输入 $0.435/1M，输出 $0.87/1M，缓存读 $0.003625/1M
- **7 日 tokens**：3,243 B
- **每会话成本**：$0.66
- **每会话 tokens**：701 万
- **缓存率**：96.5%（头部中最高）

**判断**：比 Flash 贵近 8 倍/会话，但仍有约 25% 的份额。说明 Agent 场景里，“简单任务用 Flash，复杂推理/长代码用 Pro” 的分工已经形成。

### 7.3 MiniMax-M3：最稳的“老三”

- **7 日 tokens**：1,980 B
- **每会话成本**：$0.48
- **每会话 tokens**：782 万（全平台最高之一）
- **缓存率**：94.9%

**判断**：均价不算便宜，但会话 token 量最高，说明用户愿意拿它处理长上下文任务。它是 DeepSeek 之后最稳定的调用选择。

### 7.4 Kimi K2.7 Code：垂直代码模型的爆发力

- **7 日 tokens**：408 B
- **每会话成本**：$1.02（榜单中最高）
- **每会话 tokens**：418 万
- **缓存率**：95.5%
- **周环比**：-20%

**判断**：单价贵、但代码场景接受度高。不过周环比 -20%，说明尝鲜期后能否留住用户是关键。Moonshot 需要更多代码场景的深度适配。

### 7.5 Qwen3.7 Plus：增速最快的变量

- **7 日 tokens**：212 B
- **周环比**：+33%（增速第一）
- **每会话成本**：$0.57
- **缓存率**：94.6%

**判断**：阿里通义仍在爬坡。虽然排名还在第 8，但增速是头部里最快的。如果保持这个趋势，Qwen3.7 Plus 很可能在未来一个月进入前五。

## 八、三条核心结论

### 1. DeepSeek 已经成为 Agent 平台的“默认选项”

无论是单日还是 2 个月累计，DeepSeek 都占据 67–72% 的市场份额。开发者选它的理由很简单：**便宜、好用、缓存率高**。它的两个版本形成了清晰分工：Flash 处理日常任务，Pro 处理复杂推理和长代码。

### 2. 中国模型的出海空间比想象中大

中国仅贡献 16% 的调用量，美国、巴西、德国、日本、印尼、印度、西班牙等市场都在用中国模型。拉美和东南亚新兴市场的活跃度尤其突出，这是中国 AI 出海非常积极的信号。

### 3. 第二梯队的变量是 MiniMax 和 Qwen

MiniMax-M3 已经冲到第三，但周环比在下滑；Qwen3.7 Plus 增速最快（+33%），Qwen3.7 Max 也增长 30%。未来 1–2 个月，这两家可能会重塑第二梯队排名。而 Moonshot 如果不能把 Kimi K2.7 Code 的代码优势转化为长期留存，可能会被进一步边缘化。

## 九、结语

OpenCode 这份数据的价值，不在于它告诉你哪个模型“分数最高”，而在于它告诉你：

- **开发者真正在用什么**
- **他们愿意为哪种能力付费**
- **这些用户来自哪里**

从全球分布来看，AI 应用已经不再是中美两国的独角戏，拉美、东南亚、欧洲、印度都在进入赛场。而对于普通开发者来说，这意味着：**选对模型、用好缓存、盯紧成本，就是在这一轮 Agent 浪潮里最简单的生存法则。**
