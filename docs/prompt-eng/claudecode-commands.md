# Claude Code 速查表

本页面汇集了值得牢记的词汇、命令和键盘快捷键。在使用 Claude Code 的前几周，请在浏览器标签页中打开此页面（或打印放在键盘旁边）。新用户遇到的大部分问题都源于不知道某个命令已经存在，因此在寻求变通方案之前快速浏览一下通常会很有帮助。

---

## 术语表

| 术语 | 定义 |
|------|------|
| **会话** | 在一个目录中运行一次 `claude`，从启动到退出。每个会话都有自己的对话历史，而项目记忆（`CLAUDE.md`）在会话之间持久保存。 |
| **上下文窗口** | 模型一次可以保存的文本总量——你的提示、Claude 的回复以及它读取的任何文件。当填满时，较早的内容会被压缩或删除。它通过 `/clear` 和 `/compact` 进行管理。 |
| **令牌** | 模型用来衡量文本的单位（大约是一个单词的 ¾）。使用限制和 API 计费都以令牌计算。你主要会通过 `/cost` 或上下文指示器遇到这个概念。 |
| **CLAUDE.md** | 一个 markdown 文件（项目根目录、主目录或子文件夹），Claude 在每个会话开始时会自动读取。它保存你的项目约定、命令和约束，这样你就不必重复输入。 |
| **计划模式** | 一种只读模式，Claude 在其中探索、解释和提议，但不会编辑文件或运行命令。在让 Claude 执行之前使用它来审查方案。使用 **Shift+Tab** 切换或使用 `/plan` 直接进入。 |
| **接受编辑模式** | 一种模式，在会话的其余部分自动批准文件编辑，而其他操作（如 shell 命令）仍需提示确认。一旦你信任工作方向并且不再想确认每个差异，这就很有用。使用 **Shift+Tab** 切换。 |
| **权限** | 管理 Claude 可以在不询问的情况下执行哪些操作的规则。默认情况下，它会询问所有涉及你的机器的操作。你可以使用 `/permissions` 或在设置中按项目调整这些权限。 |
| **工具** | Claude 可以调用的功能，例如读取文件、编辑、运行 bash 或搜索网络。每个工具调用都会出现在记录中，这样你可以准确看到发生了什么。 |
| **MCP（模型上下文协议）** | 一个开放标准，用于将外部系统（如 GitHub、Jira、数据库或内部 API）作为工具插入 Claude。如果你的团队配置了 MCP 服务器，Claude 可以直接查询和操作这些系统。 |
| **子代理** | 主会话可以生成的辅助 Claude 实例，用于处理专注的子任务，例如运行测试、搜索大型代码库或审查代码，在其自己的上下文窗口中进行，然后报告结果。子代理通过 `/agents` 配置。 |
| **钩子** | 在 Claude 生命周期中的定义点自动运行的 shell 命令，例如在工具运行之前、编辑之后或会话开始时。钩子通常用于自动格式化、linting 或阻止不安全的命令。 |
| **技能** | 一套打包的指令和辅助文件，教 Claude 特定的工作流程，例如生成 PDF 报告、搭建组件或遵循部署运行手册。技能像内置命令一样使用 / 调用，也可以在相关时自动加载。 |
| **命令** | 任何以 / 开头的输入。内置命令控制会话（见下表）；自定义命令是你的团队在 `.claude/skills/<name>/SKILL.md` 中定义的技能（旧版 `.claude/commands/` 路径仍然有效）。 |

## 命令

在空提示符上输入 `/` 可以查看你的设置中可用的每个命令，包括自定义、插件和 MCP 提供的命令。下表涵盖了内置默认值（以及随每次安装一起提供的捆绑技能），这些是你在学习该工具时最常使用的。某些条目因平台和计划而异。

| 命令 | 功能 |
|------|------|
| `/help` | 列出所有可用命令。 |
| `/init` | 探索代码库并生成启动 `CLAUDE.md`。 |
| `/clear` | 清除对话历史并重新开始（项目记忆保留）。别名：`/reset`、`/new`。 |
| `/compact` | 总结到目前为止的对话以释放上下文。接受可选的焦点指令。 |
| `/btw` | 提出一个快速的附带问题，而不将其添加到主对话或消耗上下文。 |
| `/rewind` | 将对话和/或代码回滚到较早的检查点。 |
| `/model` | 查看或切换活跃模型。 |
| `/cost` | 显示此会话的令牌使用情况和支出。 |
| `/usage` | 显示您的计划使用限制和当前速率限制状态。 |
| `/context` | 可视化当前加载到上下文窗口中的内容及其支出位置。 |
| `/memory` | 查看或编辑范围内的 `CLAUDE.md` 文件。 |
| `/add-dir` | 为此会话授予 Claude 对其他目录的文件访问权限。 |
| `/permissions` | 查看或更改哪些工具需要批准。 |
| `/config` | 打开配置设置（主题、默认值、编辑器模式）。别名：`/settings`。 |
| `/plan` | 直接进入计划模式，可选择带有任务描述。 |
| `/diff` | 打开未提交更改和每轮差异的交互式查看器。 |
| `/copy` | 将最后一个响应（或选定的代码块）复制到您的剪贴板。 |
| `/export` | 将当前对话保存到文件或剪贴板。 |
| `/mcp` | 管理 MCP 服务器连接和身份验证。 |
| `/agents` | 列出、创建或编辑子代理。 |
| `/hooks` | 查看工具事件的钩子配置。 |
| `/skills` | 列出此会话中可用的技能。 |
| `/simplify` | 捆绑技能：审查您最近更改的文件以查找重用、质量和效率问题，然后应用修复。 |
| `/status` | 显示账户、模型、工作目录和版本。 |
| `/doctor` | 诊断安装和环境问题。 |
| `/feedback` | 向 Anthropic 报告问题并附加会话上下文。别名：`/bug`。 |
| `/resume` | 重新打开之前的会话并继续您离开的地方。别名：`/continue`。 |
| `/login` / `/logout` | 身份验证、切换账户或登出。 |
| `/exit` | 退出 CLI。别名：`/quit`。 |

## 键盘快捷键

| 按键 | 操作 |
|------|------|
| **Shift + Tab** | 循环权限模式：`default → acceptEdits → plan`。运行 `claude --enable-auto-mode` 后也包括自动模式，以及启用该模式时的 `bypassPermissions`。 |
| **Esc** | 在Claude响应中断它，以便您可以再次输入。 |
| **Esc, Esc** | 打开回放/检查点菜单，以回滚到会话中的较早时间点。 |
| **Ctrl + C** | 取消当前输入，或在空提示符上退出。 |
| **Ctrl + R** | 反向搜索您的提示历史记录。 |
| **Ctrl + O** | 展开到详细的完整记录视图。 |
| **↑ / ↓** | 滚动浏览您的提示历史记录。 |
| **`@` + 路径** | 在提示中引用文件或目录。 |
| **`/`** | 打开命令菜单。 |
| **`?`** | 显示当前终端或IDE的快捷方式。 |

快捷方式因终端和IDE而略有不同。在会话中按 **`?`** 以获取您环境中的确切列表。
